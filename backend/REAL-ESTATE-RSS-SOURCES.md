## 📊 Как добавить источники:

### Через интерфейс:
1. Откройте вкладку **"Новости"**
2. Перейдите в **"Источники"**
3. Нажмите **"Добавить источник"**
4. Заполните:
   - Название: например "РБК Недвижимость"
   - URL: `https://www.rbc.ru/reality/rss/`
   - Тип: RSS лента
5. Нажмите **"Сохранить"**
6. Нажмите **"Запустить"** для парсинга

### Через API:
```bash
# Пример добавления источника
curl -X POST http://localhost:3000/api/news/sources \
  -H "Content-Type: application/json" \
  -d '{
    "name": "РБК Недвижимость",
    "type": "rss",
    "url": "https://www.rbc.ru/reality/rss/"
  }'
```

## ⚙️ Настройка AI обработки:

AI автоматически обрабатывает каждую новость:
- ✅ Перефразирует текст (humanizer)
- ✅ Сохраняет важные факты
- ✅ Добавляет ссылку на источник
- ✅ Генерирует хештеги
- ✅ Создаёт пост для соцсетей (150-300 слов)

Для работы AI нужен ключ GEMINI_API_KEY (уже настроен в вашем .env).

## 🔄 Автоматический парсинг:
