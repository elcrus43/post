## 📋 ак использовать:

### убликация из очереди:

1. ткройте раздел "Queue" в приложении
2. ыберите платформы (TG/VK) для публикации
3. ажмите "едактировать" если нужно изменить текст
4. обавьте эмодзи через кнопку 😊
5. ажмите "публиковать"

### убликация через Telegram бота:

**:** ля публикации из бота в группы нужно:

1. **обавить бота в группы:**
   - ля TG: обавьте бота как администратора в группу
   - ля VK: от должен иметь права на публикацию в сообществе

2. **астроить webhook для бота:**
   ```javascript
   // ужно добавить endpoint для получения сообщений от бота
   app.post('/api/telegram/webhook', async (req, res) => {
     // бработка ответов "approve" от пользователя
   });
   ```

3. **льтернативный вариант - использовать QueuePage:**
   - Telegram уведомление приходит с текстом поста
   - ткройте приложение → Queue
   - ажмите "публиковать" для выбранных платформ
